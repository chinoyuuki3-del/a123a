# Troll Engine Friend Invite Sync

Troll Engineで、友達を短い招待コードだけで追加するための設定リポジトリです。

## 使い方

1. 招待する側が「友達招待」を開きます。
2. 相手に付けたい名前を入力して、短い招待コードを作ります。
3. 友達へ `FR-7K2M9` のようなコードを伝えます。
4. 友達がコードを入力して参加すると、両方の端末へ友達が登録されます。

- ユーザー登録はありません。
- パスワードやメールアドレスは使いません。
- API URLの設定はありません。
- 招待コードは10分間・1回だけ有効です。
- 招待する側と参加する側の両方がTroll Engineを開いている必要があります。
- ユーザー情報・友達情報・チャット内容をこのGitHubリポジトリへ保存しません。

`data/invite.json` は招待機能の公開設定だけを配信します。
